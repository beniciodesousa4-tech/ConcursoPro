CONTA E SINCRONIZAÇÃO

Configuração

Conecte o app a um projeto Firebase seu para armazenar os dados na nuvem.

Configuração do Firebase

Os dados não serão sincronizados até você configurar Firebase Authentication, Firestore Database e Storage.

A configuração é pública por natureza, mas a segurança depende das regras do Firebase. Nunca coloque uma chave privada de servidor aqui.

Como funciona a privacidade

  • Use este app para sua própria conta e não compartilhe o endereço privado.
  • Configure regras para que cada usuário só leia e altere seus próprios documentos e arquivos.
  • Não habilite acesso irrestrito de leitura/escrita no Firestore ou Storage.
  • Este MVP usa autenticação anônima; para manter a conta entre dispositivos com segurança, adicione login por e-mail antes de uso definitivo.
